renut-nx web installer

Builds the Nintendo Switch package of Banjo-Kazooie: Nuts & Bolts from your own copy. Everything runs in this browser: nothing is uploaded.

version 1.0.1

1. Choose your game

Your Xbox 360 disc as an .iso, or the folder it was extracted to (with default.xex and Bundle in it).

Nothing chosen yet.

2. Choose title update 3 (and the DLC)

renut-nx is the updated game: choose title update 3's package (TU_16L61VD_0000004000000.00000000000O1, the file inside the update's folder 3E567DFF). Add the DLC package, L.O.G.'s Lost Challenges (E41F20AAF7094B9AFCA8CC90489D689D72A5062B4D), at the same time if you have it. Both are read in place.

Nothing chosen yet.

3. Create the package

Who compiles the shaders?

Either way the page first makes the game's shaders from your files. The zip then downloads while it is written (about 7 GB).

4. Copy it to the Switch

  1. Extract renut-nx.zip to the root of the SD card: it makes switch/renut-nx/.
  2. In Sphaira, find Banjo-Kazooie Nuts & Bolts, press X to open Options and choose Install Forwarder. Make sure Address Space is set to 39-bit, choose Create Forwarder, then start the game from the Home Screen. This lets the game use all four CPU cores, which it cannot do through a title takeover. The first start sets this up; from the second start on the game runs on four cores. The very first start also takes a few seconds longer: renut-nx compresses its shader package once.
  3. Settings are in switch/renut-nx/renut.toml.
